HTML5

HTML5 es el lenguaje utilizado para estructurar el contenido de las páginas y aplicaciones web.

El navegador interpreta las etiquetas HTML y construye con ellas la estructura que posteriormente será presentada al usuario.

Concepto clave HTML se encarga principalmente de la estructura y significado del contenido , no de su apariencia visual.

1.1. Estructura básica de HTML

Un documento HTML comienza con una declaración del tipo de documento y contiene normalmente las secciones head y body. 

<!DOCTYPE html>

<html lang="es">

<head>

    <meta charset="UTF-8">

    <title>
        Mi página web
    </title>

</head>

<body>

    <h1>
        Mi primera página
    </h1>

    <p>
        Hola mundo.
    </p>

</body>

</html>

1.2. Etiquetas HTML

Las etiquetas permiten indicar qué representa cada contenido dentro del documento.

  • Encabezados.
  • Párrafos.
  • Enlaces.
  • Imágenes.
  • Listas.
  • Tablas.
  • Formularios.

1.3. Etiquetas semánticas

Las etiquetas semánticas describen mejor la función que desempeña cada parte del documento.

  • <header>
  • <nav>
  • <main>
  • <section>
  • <article>
  • <aside>
  • <footer>

1.4. Enlaces

Los enlaces permiten conectar documentos y recursos diferentes. 

<a href="contacto.html">
    Contacto
</a>

1.5. Imágenes 

<img
    src="imagen.jpg"
    alt="Descripción de la imagen">
Importante El atributo alt proporciona una descripción alternativa de la imagen y mejora la accesibilidad.

1.6. Listas

HTML permite crear listas ordenadas y no ordenadas. 

<ul>

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ul>

1.7. Tablas

Las tablas permiten representar información organizada en filas y columnas.

1.8. Formularios

Los formularios permiten recoger información introducida por el usuario. 

<form>

    <label>
        Nombre:
    </label>

    <input
        type="text"
        name="nombre">

    <button type="submit">
        Enviar
    </button>

</form>

1.9. Multimedia

HTML5 incorpora elementos para trabajar directamente con contenido multimedia.

  • Audio.
  • Vídeo.
  • Contenido incrustado.

1.10. SEO básico

Una estructura HTML correctamente organizada facilita que los motores de búsqueda interpreten el contenido de una página.

1.11. Accesibilidad

La accesibilidad busca que el contenido web pueda ser utilizado por el mayor número posible de personas.

2. CSS3

CSS3

CSS3 permite controlar la presentación visual de los documentos HTML.

Mediante CSS podemos controlar colores, tipografías, tamaños, espacios, distribución, animaciones y adaptación a diferentes dispositivos.

2.1. Selectores

Los selectores permiten seleccionar los elementos HTML a los que queremos aplicar estilos. 

p {

    color: black;

}

h1 {

    font-size: 40px;

}

2.2. Colores

CSS permite utilizar diferentes formas para definir colores.

  • Nombres de colores.
  • HEX.
  • RGB.
  • RGBA.

2.3. Tipografías

Las propiedades relacionadas con el texto permiten controlar el tipo de letra, tamaño, grosor, alineación y otros aspectos.

2.4. Modelo de caja

Cada elemento HTML puede entenderse como una caja compuesta por contenido, padding, borde y margen.

Recuerda El modelo de caja es fundamental para comprender cómo se calcula el espacio ocupado por los elementos.

2.5. Flexbox

Flexbox permite distribuir y alinear elementos dentro de un contenedor de forma flexible. 

.contenedor {

    display: flex;

    justify-content: center;

    align-items: center;

}

2.6. Grid Layout

CSS Grid permite crear estructuras basadas en filas y columnas. 

.galeria {

    display: grid;

    grid-template-columns:
        repeat(3, 1fr);

    gap: 20px;

}

2.7. Responsive Design

El diseño responsive permite adaptar una página a ordenadores, tablets y teléfonos móviles. 

@media (max-width: 768px) {

    .contenedor {

        width: 100%;

    }

}

2.8. Transiciones 

button {

    transition: .3s;

}

button:hover {

    transform: translateY(-3px);

}

2.9. Animaciones 

@keyframes flotar {

    0% {

        transform: translateY(0);

    }

    50% {

        transform: translateY(-20px);

    }

    100% {

        transform: translateY(0);

    }

}

2.10. Variables CSS 

:root {

    --celeste: #38bdf8;

    --negro: #080b12;

}

.titulo {

    color: var(--celeste);

}
Ejemplo práctico Las variables CSS permiten definir un color una sola vez y reutilizarlo en diferentes partes de una página.

3. JavaScript

JAVASCRIPT

JavaScript es el lenguaje de programación que permite añadir comportamiento e interacción a las páginas web.

Concepto clave HTML estructura la página, CSS define su apariencia y JavaScript permite programar su comportamiento.

3.1. Variables 

let nombre = "Carlos";

let edad = 25;

3.2. Tipos de datos

  • String.
  • Number.
  • Boolean.
  • Array.
  • Object.

3.3. Operadores

Los operadores permiten realizar operaciones matemáticas, comparaciones y operaciones lógicas.

3.4. Condicionales 

if (edad >= 18) {

    console.log("Mayor de edad");

} else {

    console.log("Menor de edad");

}

3.5. Bucles 

for (let i = 0; i < 5; i++) {

    console.log(i);

}

function saludar(nombre) {

    return "Hola " + nombre;

}

console.log(
    saludar("Carlos")

    "HTML",

    "JavaScript"

3.8. Objetos 

const alumno = {

    nombre: "Carlos",

    curso: "Desarrollo Web"

3.9. Eventos

Los eventos permiten ejecutar código cuando ocurre una acción determinada, como hacer clic en un botón o enviar un formulario. 

document
    .getElementById("boton")
    .addEventListener("click", function() {

        alert("Has pulsado el botón");

    });

3.10. DOM

El DOM representa el documento HTML como una estructura de objetos que JavaScript puede modificar. 

const titulo =
    document.getElementById("titulo");

titulo.textContent =
    "Nuevo título";

3.11. Formularios

JavaScript puede obtener los datos introducidos por el usuario, validarlos y responder ante el envío del formulario.

3.12. Temporizadores 

setTimeout(function() {

    console.log("Han pasado 2 segundos");

}, 2000);

3.13. Programación dinámica

La combinación de JavaScript y DOM permite modificar dinámicamente el contenido de una página sin necesidad de recargarla completamente.

4. Desarrollo Web

4. Desarrollo Web

DESARROLLO WEB

Una aplicación web completa no está formada únicamente por HTML, CSS y JavaScript. También puede necesitar un servidor, una base de datos y diferentes servicios.

4.1. Modelo cliente-servidor

El cliente realiza una petición al servidor. El servidor procesa la solicitud y devuelve una respuesta.

4.2. HTTP y HTTPS

HTTP permite la comunicación entre clientes y servidores web. HTTPS incorpora cifrado para proteger dicha comunicación.

4.3. Bases de datos

Las bases de datos permiten almacenar y gestionar información de manera estructurada.

4.4. SQL 

SELECT nombre
FROM usuarios
WHERE edad >= 18;

4.5. Operaciones CRUD

  • Create — Crear.
  • Read — Leer.
  • Update — Actualizar.
  • Delete — Eliminar.

4.6. APIs

Una API permite que diferentes aplicaciones puedan comunicarse entre ellas.

4.7. Despliegue

El despliegue consiste en preparar y publicar una aplicación para que pueda ser utilizada en un entorno real.

4.8. Pruebas

  • Pruebas funcionales.
  • Pruebas de navegación.
  • Pruebas responsive.
  • Pruebas de formularios.
  • Pruebas de compatibilidad.

4.9. Documentación

Documentar correctamente un proyecto facilita su mantenimiento y permite que otros desarrolladores comprendan su funcionamiento.

5. Proyecto Final

El objetivo final es integrar los conocimientos adquiridos durante el curso para construir una aplicación web completa.

📄

HTML

Crear la estructura y organizar correctamente el contenido.

🎨

CSS

Diseñar la interfaz, hacerla responsive y añadir efectos visuales.

⚙️

JavaScript

Añadir interacción, eventos, validaciones y comportamiento dinámico.

🚀

Preparar el proyecto y publicarlo en un entorno web.

Objetivo final Ser capaz de pasar de una idea a una aplicación web funcional utilizando las tecnologías aprendidas durante la formación.
