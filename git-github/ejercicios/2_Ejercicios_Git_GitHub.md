# 2. Ejercicios Git y GitHub

## Pregunta 1

¿Cuál es el objetivo principal de Git?

A) Guardar y controlar las diferentes versiones de un proyecto

B) Crear páginas web automáticamente

C) Diseñar bases de datos

D) Gestionar correos electrónicos

<details>
<summary>Ver solución</summary>

```text
Respuesta correcta: A

Explicación:
Git permite registrar y controlar los cambios realizados en los archivos de un proyecto a lo largo del tiempo.
```

</details>
