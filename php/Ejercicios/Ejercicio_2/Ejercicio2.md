# PHP. Ejercicio 2.

Mejora el Ejercicio 1 con las siguientes funcionalidades.

- El formulario debe tener un grupo de tipo RadioButton que permita seleccionar el sexo de la persona.

- El formulario debe tener un apartado que permita seleccionar los meses del año en los que el usuario prefiere sus vacaciones. El usuario puede tiene que elegir al menos un mes del año, y como máximo puede elegir 3 meses. Si no lo hace de esta manera, debe mostrarse un mensaje de error.

- El formulario debe contener un menú desplegable me muestre el estado civil del usuario. Los posibles estados son: Soltero, Casado, Divorciado y Otros.

- El formulario debe contener un área de texto en la que el usuario pueda solicitar sus periodos de vacaciones escribiendo las fechas en las que las desea disfrutar.

Al pulsar el botón de Enviar del formulario, se deben mostrar los valores que ha introducido el usuario.

Una vez realizado el ejercicio, publica el código en un directorio dentro del directorio Ejercicio2.
