# Ejercicios MVC y Testing

## Pregunta 1

¿Cuál es el principal objetivo del patrón MVC?

A) Mejorar la velocidad de Internet

B) Organizar la aplicación separando responsabilidades

C) Eliminar la necesidad de pruebas

D) Sustituir las bases de datos

<details>
<summary>Ver solución</summary>

```text
Respuesta correcta: B

Explicación:
MVC organiza una aplicación dividiéndola en componentes con responsabilidades diferentes, facilitando el mantenimiento y la comprensión.
```

</details>
