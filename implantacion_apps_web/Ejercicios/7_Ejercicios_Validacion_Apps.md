# 7. Ejercicios Validación Apps Web

## Pregunta 1

¿Cuál es el principal objetivo de la verificación de una aplicación web?

A) Diseñar la apariencia de la aplicación.

B) Comprobar que la aplicación funciona correctamente.

C) Crear nuevas funcionalidades.

D) Instalar servidores.

<details>
<summary>Ver solución</summary>

```text
Respuesta correcta: B

Explicación:
La verificación permite comprobar que la aplicación cumple los requisitos y funciona correctamente antes de ser utilizada por los usuarios.
```

</details>
