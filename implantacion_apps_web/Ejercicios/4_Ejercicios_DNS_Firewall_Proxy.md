# 4. Ejercicios DNS, Firewall, Proxy.

## Pregunta 1

¿Cuál es la función principal de un DNS?

A) Bloquear páginas web peligrosas.

B) Traducir nombres de dominio en direcciones IP.

C) Almacenar páginas web.

D) Crear usuarios de Internet.

<details>
<summary>Ver solución</summary>

```text
Respuesta correcta: B

Explicación:
El DNS permite convertir nombres fáciles de recordar, como www.empresa.com, en direcciones IP que los equipos utilizan para comunicarse.
```

</details>
