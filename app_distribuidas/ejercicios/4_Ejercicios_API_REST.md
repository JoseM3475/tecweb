## Pregunta 1

¿Qué es una API?

A) Un lenguaje de programación

B) Un conjunto de reglas que permite que aplicaciones se comuniquen entre sí

C) Una base de datos

D) Un sistema operativo

<details>
<summary>Ver solución</summary>

```text
Respuesta correcta: B

Explicación:
Una API permite que diferentes aplicaciones intercambien información siguiendo unas reglas definidas.
```
